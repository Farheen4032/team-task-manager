# 🚀 Team Task Manager (MERN Stack)

A full-stack Task Management Web Application built using **MongoDB, Express, React, and Node.js (MERN)**.  
It allows users to manage tasks, projects, and track progress with role-based access (Admin/User).

---

## 🌐 Live Demo

👉 Frontend: https://team-task-manager.vercel.app  
👉 Backend: https://team-task-api.onrender.com  

---

## 📌 Features

- 🔐 User Authentication (Login/Register)
- 👨‍💼 Role-based Access (Admin / User)
- 📁 Project Management (Create & View Projects)
- ✅ Task Management (Create, Update, Delete Tasks)
- 📊 Dashboard with Task Statistics
- 🔍 Search & Filter Tasks
- ⚠️ Overdue Task Highlighting

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Axios
- React Router DOM
- CSS (Inline Styling)

**Backend:**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Bcrypt.js
